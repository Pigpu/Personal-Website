# 首页内容维护

管理员登录本地预览后，首页上方有“编辑首页”和“管理语录”；Logo 下方的“最近在听”旁有“更新”。所有保存操作都由后端验证管理员 JWT，普通注册账号不能修改。

- **简介与联系**：同一个窗口分别维护中文、英文、日文。可编辑两段简介、公开联系方式和补充联系说明；问候语、Logo 和署名保留。留空的段落会隐藏，输入按纯文本展示，支持换行。
- **语录**：在简介与跳转链接之间展示，支持句子、可选来源、语言和启用状态。“三种语言通用”的句子可在所有语言中出现。停用不删除记录，可以重新启用。每次完整进入或刷新网页重新选择，站内跳转保留当前选择；不同语言各自选择适用内容。没有适用语录时不占位。
- **最近在听**：手工填写歌手名、歌曲名和 HTTPS 网易云歌曲链接，并勾选显示。数据库只保留当前这一条，每次保存覆盖旧歌曲，不记录历史。支持 `music.163.com/#/song?id=…`、`music.163.com/song?id=…` 和 `y.music.163.com/m/song?id=…`，保存时统一成歌曲链接并去掉分享参数。点击打开新标签页，不自动播放；关闭显示后保留已填写信息。
- **导航栏倒计时**：管理员点击倒计时（首次为“设置倒计时”），修改事件名称和目标日期。数据库始终只保留当前一条配置，所有访客刷新页面读取同一份设置。剩余天数按访客本地日历日期计算，当日和已过期均显示 `D−0`。名称和日期不随界面语言翻译。
- 首次部署共享倒计时后，普通访客在尚未设置时不显示倒计时。管理员若使用原先修改过倒计时的同一浏览器，编辑窗口会填入有效的旧本地设置；只有点击保存才会上传。数据库有配置后不再使用任何浏览器旧值，也不会回退到写死的“JLPT N2”。读取失败会提示暂不可用，保存失败保留输入内容。
- 管理窗口提供未保存提醒。语录和歌曲库初始为空，不会自动填入站长尚未选择的内容。

## 数据库和上线

**2026-10-25 更新**：正式数据库已完成本次六张新增表的创建，前后端应用尚未部署。合并 SQL 与执行结果见 `docs/database-preparation-2026-10-25.md`；下文描述的是最初的本地开发步骤。

新增 `homepage_translations`、`homepage_quotes`、`homepage_listening`、`homepage_countdown` 四张 PostgreSQL 表。可重复执行的建表脚本在 `portfolio-backend/src/main/resources/db/manual/homepage.sql`，只新增表，不清理已有数据。

`homepage_listening` 固定使用主键 `id = 1`，数据库 CHECK 约束禁止其他主键；配合主键唯一性，表中最多一条记录。建表脚本初始化一条空记录。保存使用原子覆盖写入，即使同时保存也不会增加历史行。

`homepage_countdown` 同样使用固定主键 `id = 1`、CHECK 约束和原子覆盖写入，最多一条记录。只保存事件名称（最多120字）和目标日期，不存剩余天数，不自动填入猜测的考试日期。建表后需由管理员首次保存。

本地已执行脚本；首次保存简介前使用原有三语文案。现有开发环境的 `ddl-auto=update` 也会在后端启动时创建缺失的表。

正式上线时需要部署前后端两部分，并确保正式数据库也有这四张表（可提前执行上述脚本；以前执行过的也可以重新执行来新增倒计时表）。部署后管理员确认并保存一次倒计时，再用其他浏览器验证。此次工作只更新本机代码和本地数据库，没有访问线上数据库。

## 接口

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| GET | `/api/home` | 公开读取三语介绍和可见歌曲 |
| GET | `/api/home/quote?lang=zh` | 公开随机语录；无内容返回 204 |
| PUT | `/api/home/admin/profile` | 管理员保存全部三语内容 |
| GET / POST | `/api/home/admin/quotes` | 管理员读取列表 / 添加语录 |
| PUT | `/api/home/admin/quotes/{id}` | 管理员编辑或停用 / 启用语录 |
| GET / PUT | `/api/home/admin/listening` | 管理员读取 / 更新歌曲，含隐藏状态 |
| GET | `/api/home/countdown` | 公开读取共享倒计时；未设置返回204 |
| PUT | `/api/home/admin/countdown` | 管理员覆盖当前倒计时，提交 `event` 和 `targetDate`（YYYY-MM-DD） |

公开读取响应禁止缓存；管理接口不能通过修改浏览器里的角色字段绕过权限。

## 验证

前端执行 `npm run build`、`npm run test:homepage` 和 `npm run test:countdown`（日期、时区与夏令时、旧值草稿、接口读取及失败处理）。后端执行 `mvnw.cmd test`，包含真实 JWT 的管理员 / 普通用户权限测试、输入校验，以及 PostgreSQL 持久化测试。倒计时测试覆盖反复更新后仅有一条配置、额外主键被拒绝、合法闰日及非法日期。持久化测试使用本地 `application.yml` 的数据库配置，数据变更在测试结束后事务回滚。
