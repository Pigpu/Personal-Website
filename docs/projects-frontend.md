# 作品页面改造

- `/projects` 沿用首页的蓝白主题、固定背景曲线和音符；桌面保持三列作品卡片，容器由原先约1280px收至1120px，卡片约缩小12%，并收紧内边距及圆角。中等屏幕两列、手机一列。
- 管理员的“发布新作品”移至标题右侧，不再占用第一张卡片；每张卡片保留编辑、删除入口，触屏和键盘操作也可直接访问。
- 搜索保留原来的标题/简介搜索接口；“最新发布”“最多点赞”在搜索结果中仍生效，不会清空关键词。输入有短暂防抖，旧请求不会覆盖新结果。封面加载失败时显示占位，加载失败提供重试。删除确认使用与生活页一致的白底蓝字窗口。
- `/projects/upload` 同时用于发布和编辑。保留全部字段、四种分类、历史自定义分类、音频/视频选择、封面/媒体/附件链接，以及三类本地上传。上传中显示进度；失败时保留原有链接。附件可通过清空链接移除。
- 编辑页以加载完成的内容作为比较基准：未修改直接退出不提醒，修改任一字段后离开会提示，恢复原值后不提醒。站内离开提示为白底蓝字；浏览器刷新或关闭采用系统原生确认。上传或保存过程中阻止离开，避免尚未完成就误判成功。
- `/projects/:id` 同步蓝白主题，保留视频/音频播放、点赞/取消、管理员点赞明细及完整时间、附件下载。外部附件仍直接打开，历史本地附件仍走原有下载接口。用户手工添加链接的能力保留。

本次仅改动前端，不修改后端接口或数据库。没有对实际作品进行发布、编辑、删除或上传测试。

验证：`npm run build`、`npm run test:projects`。专项测试覆盖排序、实际修改检测、表单字段和链接保留、附件下载路径和上传媒体类型识别。
