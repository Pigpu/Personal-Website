# 生活板块前端样板

- `/articles`：横向文章列表，封面在左，分类、标题、正文摘录、浏览量、点赞数和发布日期在右。支持时间和点赞数两个排序字段，各自可以正序或倒序。排序使用已有列表接口的数据，不修改数据库顺序。
- `/article/:id`：蓝色背景、白色阅读区域。保留点赞 / 取消点赞、管理员点赞明细、评论、回复和评论删除。管理员可从文章标题附近进入编辑。
- `/editor` 与 `/editor?id=…`：白色 Markdown 书写区，保留分类、图片上传、首张 Markdown 图片作为封面、发布和更新。编辑入口仅对管理员展示，写入权限继续由现有后端校验。
- 音符和弧线固定在视口背景，滚动文章或列表时不随内容移动。

## 草稿与离开提醒

新文章继续使用浏览器里的 `blog_draft_data` 草稿，兼容旧草稿格式，并额外保留分类。恢复提示和站内离开确认都采用白底蓝字的原生模态窗口。

编辑已有文章时，加载后的内容作为比较基准。只在标题、正文或分类真正发生变化后提示未保存；撤销到原内容后不再提示。确认离开时由路由继续原导航，保留目标查询参数和浏览器前进 / 后退行为。

刷新或关闭浏览器标签时仍由浏览器显示原生未保存提醒；网页不能定制该系统提示的外观。

保存失败会保留当前编辑内容。新文章发布成功才清理本机草稿，编辑现有文章不会清除另一篇尚未发布的新文章草稿。保存或上传图片期间阻止站内离开，避免中断操作。

## 验证

`npm run build` 检查类型和生产构建；`npm run test:articles` 验证双向排序、摘要提取、草稿兼容、分类变化和未修改状态判定。这次没有修改后端接口或数据库，也没有发布、编辑、删除真实文章作为测试。
