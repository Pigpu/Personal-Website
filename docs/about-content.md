# 关于页与友情链接

`/about` 使用现有蓝白主题、固定角落弧线和音符。介绍采用开放段落布局，技术栈区域已移除，替换为友情链接。原有邮箱及 X、YouTube、Bilibili 入口保留。

管理员登录后：

- 右上角“编辑介绍”可分别维护中文、英文、日文的标题和两段介绍。切换语言保留输入，保存时一起更新三种语言。留空的段落不显示。首次保存前使用原有三语文案；可直接将旧介绍更新为目前的研究生身份。
- “添加友情链接”填写网站名称、完整 HTTP/HTTPS 链接、可选简短介绍。网站名称和介绍全站共用，不自动翻译。每条链接旁有编辑、删除入口；删除前确认，编辑保留原记录身份。所有友情链接和原社交链接都在新窗口打开，并隔离新窗口对来源页的访问。
- 编辑器按实际字段变化判断未保存状态，切换语言不会丢失内容。关闭窗口、站内跳转前提供同主题的放弃修改提醒；刷新/关闭浏览器使用系统原生确认。保存失败保留内容。读取失败提供重试，避免把未读到的旧数据覆盖为空。

介绍和友情链接均由服务器保存；访客刷新即可读到共享内容，不使用浏览器本地存储。标题、段落和名称均按纯文本渲染，支持段落换行。后端只接受 HTTP/HTTPS 网页链接，不抓取外部网站、图标或预览。

## 数据库与部署

新增 `about_translations`（主键为语言，保存中英日三行，更新覆盖原值）和 `friend_links`（每个网站一行，编辑更新原行，删除真正移除记录）。没有初始化虚构的友情链接。

可重复建表脚本：`portfolio-backend/src/main/resources/db/manual/about.sql`。本地执行后可直接预览；正式部署时需要更新前后端，并在正式数据库执行脚本或确保相应表已经创建。此任务不操作线上数据库。

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| GET | `/api/about` | 公开读取三语介绍与友情链接，`Cache-Control: no-store` |
| PUT | `/api/about/admin/profile` | 管理员保存全部三语介绍 |
| POST | `/api/about/admin/links` | 管理员添加友情链接 |
| PUT | `/api/about/admin/links/{id}` | 管理员更新现有友情链接 |
| DELETE | `/api/about/admin/links/{id}` | 管理员删除友情链接 |

后端验证管理员 JWT；修改浏览器角色字段不能绕过权限。输入长度：标题/网站名120、每段介绍10000、链接2000、友情链接介绍500。

## 验证

前端：`npm run build`、`npm run test:about`，以及现有回归测试。后端：`mvnw.cmd test`，覆盖公开读取、管理员与普通用户权限、网址与长度校验、三语持久化和覆盖更新、友情链接增删改。数据库测试均使用本地 PostgreSQL 并在测试结束时回滚。
