# 独享音频入口和听众管理

作品页增加“独享音频”入口，管理员和已授权账号可见。入口共用 `/premium-admin` 节目列表：管理员标题为“私密音频管理”，其他获准账号标题为“私密音频”，不再显示小标题。普通听众仅可打开收听页；发布节目、复制链接、管理听众仅向管理员显示，并由后端权限规则保护。

管理员可在“管理听众”中搜索已注册账号（最多20个结果），也可输入完整用户名直接添加；可随时移除授权。操作保存到 `premium_listeners`，以用户 ID 作为唯一主键，不改变用户角色或密码，不积累重复授权记录。管理员默认拥有访问权限，无需添加。

按本次明确选择，授权只限制入口和节目列表。原 `/exclusive-player/:uuid` 链接及公开播放接口继续允许直接收听。移除听众不会使之前分享的链接失效。

## 接口

- `GET /api/premium/access`：当前访问者是否可看入口和列表、是否为管理员；不缓存。
- `GET /api/premium/list`：仅管理员和已授权账号可读；只返回节目 ID、UUID、标题和日期。
- `GET /api/premium/admin/listeners`：管理员查看已授权账号。
- `GET /api/premium/admin/users?query=...`：管理员按用户名搜索，只返回必要的账号信息。
- `POST /api/premium/admin/listeners`：管理员提交 `userId` 或完整 `username` 添加账号。
- `DELETE /api/premium/admin/listeners/:userId`：管理员移除授权。

每次访问权限接口和列表时均查询服务器状态，移除授权后无需重新签发登录令牌。已经打开的页面在下一次进入或刷新列表时更新状态。未授权账号直接访问列表接口会返回403，不能通过修改浏览器中保存的角色获得权限。

## 上线顺序

1. 备份服务器原前端目录及正式 JAR。
2. 在网站的 PostgreSQL 数据库中执行 `portfolio-backend/src/main/resources/db/manual/premium-listeners-2026-10-28.sql`。仅新增授权表，不改已有账号或节目。
3. 替换后端同名 JAR，沿用 Java21 和 `--spring.profiles.active=prod`，重启后端。
4. 更新前端，保留 `.well-known`、`.user.ini`、旧 assets 及原上传资源。
5. 管理员打开作品页，经“独享音频”进入并添加一个普通账号。使用该账号验证入口和列表，再移除授权验证入口与列表不可访问。最后在未登录窗口检查原分享链接仍可收听。
